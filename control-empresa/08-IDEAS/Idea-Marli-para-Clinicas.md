# Idea · Marli para Clínicas

Versión del producto orientada a la
[[../07-CLIENTES/Buyer-Persona-Clinica|Persona 3]].

## Hipótesis

Las clínicas de 2-6 psicólogos pagarían entre 2.000-4.000€ por una
versión multi-usuario con:

- Roles y permisos
- Branding adaptado
- Reporting agregado para dirección
- Mantenimiento prioritario

## Validación

- 3 conversaciones con clínicas en Fase 1 antes de construir
- Si 2/3 muestran intención de compra → desarrollar

## Roadmap mínimo

1. Fork del CRM Notion con multi-tenant lite
2. Permisos por rol (psicólogo / admin)
3. Dashboard agregado para dirección
4. Branding configurable

## Riesgo

- Soporte enterprise consume mucho tiempo del founder
- Margen menor por euro/hora si no se sistematiza
