# Marli Agency · Sistema de automatización basado en skills

Mapeo completo de los procesos de Marli Agency a skills disponibles en el
ecosistema de `npx skills`, con búsquedas reales documentadas, arquitectura
propuesta y análisis de gaps.

Documentos en este directorio:

1. `01-resumen-empresa.md` — Resumen ejecutivo de Marli (5 líneas).
2. `02-procesos-extraidos.md` — Lista estructurada de los 38 procesos
   accionables extraídos del documento maestro v3.0.
3. `03-busquedas-realizadas.md` — Bitácora completa de las búsquedas hechas
   con `npx skills` y los registries explorados.
4. `04-mapa-skills-asignadas.md` — Tabla maestra: proceso → skill → uso →
   nivel de automatización.
5. `05-arquitectura-final.md` — Arquitectura del sistema propuesto y cómo
   se integran las skills entre sí.
6. `06-gaps-y-skills-faltantes.md` — Procesos sin skill nativa, qué hace
   falta construir y por qué.
7. `07-plan-implementacion.md` — Roadmap de instalación y secuencia de
   activación alineado con el plan 90 días de Marli.
