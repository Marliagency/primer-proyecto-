# 04 — Meta Ads (Facebook + Instagram)

Toda la infraestructura de anuncios para warm-up de la audiencia ANTES del cold email + retargeting tras el tripwire.

## Inventario

| Archivo | Qué cubre |
|---|---|
| `pixel-install-hostinger.md` | Cómo instalar Meta Pixel + Conversions API en tu Hostinger |
| `custom-audiences-setup.md` | Crear las 5 audiences (lista 10k, video, engagement, web, lookalike) |
| `6-ad-creatives.md` | 6 anuncios con copy + brief de diseño + CTA + UTMs |
| `budget-targeting.md` | Budget mes 1/2/3 + targeting detallado por nivel funnel |

## Orden de ejecución

**Día 1**: instalar Pixel + Conversions API
**Día 2**: crear las 4 Custom Audiences (excepto Lookalike, requiere base)
**Día 3**: subir lista 10k psicólogos como Custom Audience
**Día 4-5**: crear 2 ads TOFU en Canva (1080×1350 + 1080×1920)
**Día 6**: lanzar Campaign 1 (TOFU) → 15€/día → empieza warm-up
**Día 21**: Custom Audiences video viewers ya tiene volumen → crear MOFU ads
**Día 30**: Campaign 2 (MOFU) live → tripwire activado
**Día 60**: Campaign 3 (BOFU) live → cierres con retargeting
