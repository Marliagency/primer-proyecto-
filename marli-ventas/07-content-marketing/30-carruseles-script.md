# 30 carruseles para Instagram + LinkedIn

Cada carrusel es 7-10 slides. **30 carruseles = 3 meses de contenido** (publicando 2-3/semana).

**Formato target**:
- IG: 1080×1350 (feed), 7-10 slides
- LinkedIn: 1080×1080 cuadrado, mismo contenido (LinkedIn permite carruseles nativos)

**Estructura común** (cada carrusel):
- Slide 1: Hook (visual + 1 frase)
- Slides 2-N: contenido valor
- Slide final: CTA suave (no "compra", sí "guarda este post")

**Tools**: Canva (gratis, plantillas Carousel) + Instagram Carousel Maker.
