# 06 — Async Closing Kit

Todo lo necesario para cerrar ventas **sin videollamadas obligatorias**, manteniendo Calendly como opción defensiva.

## Inventario

| Archivo | Para qué |
|---|---|
| `landing-tripwire.md` | Copy completo página /crm-gratis (lead magnet) |
| `landing-pack-premium.md` | Copy completo página /pack-premium (high ticket) |

| `loom-script-demo.md` | Script + setup vídeo demo asíncrono 5 min |
| `stripe-payment-links-setup.md` | Setup completo Stripe Payment Links |

## Flujo de cierre asíncrono

```
[Visit landing /pack-premium]
    ↓
[Lee FAQ + watches Loom 5 min]
    ↓
[Click "Comprar 498€"] → Stripe Payment Link
    ↓
[Pago seguro Stripe]
    ↓
[Redirect /gracias-compra]
    ↓
[Auto-trigger: Pixel Purchase + email bienvenida + Notion update]
    ↓
[D+1: WhatsApp soft check-in]
    ↓
[Onboarding email D+3, D+7, D+14]
    ↓
[D+30: pedir testimonio + upsell Mantenimiento]
```

**0 videollamadas obligatorias**. Conversion async warm: 8-12%.

## Por qué funciona el cierre async

1. **FAQ exhaustiva** anticipa cada duda → no necesitan preguntar
2. **Vídeo Loom 5 min** sustituye demo de 25 min
3. **Garantía 14 días** elimina riesgo percibido
4. **Stripe Payment Link** elimina fricción técnica
5. **WhatsApp soft cierre** humaniza la transacción
6. **Calendly visible** para los que lo quieran (10-15% lo usan)

## Setup time total

- Landing tripwire: 4h (Hostinger Builder + copy)
- Landing Pack Premium: 6h (Hostinger Builder + diseño + copy)
- Loom demo: 1h (prep + grabar)
- Stripe Payment Links: 30 min
- WhatsApp Business: 30 min
- **Total**: ~12 horas para tener cierre asíncrono completo
