## Configuración Stripe Payment Links

### Pack Premium 498€

1. Stripe Dashboard → Payment Links → Create
2. Product: "Marli — Pack Premium"
3. Price: 498€ (one-time)
4. After payment redirect to: `https://marli.agency/gracias-compra?session_id={CHECKOUT_SESSION_ID}`
5. Collect customer info: email, name, ZIP (mínimo)
6. Tax automático: ON (España 21% IVA)
7. Allow promotion codes: ON (para que puedas mandar descuentos puntuales)
8. Quantity adjustable: OFF
9. Phone collection: optional
10. Custom message after success: "Gracias por confiar en Marli — recibirás email con setup en 5 min"

→ Copia el link generado: `https://buy.stripe.com/xxx_pack`

### Pack + Instalación 1.349€

Misma config con price 1.349€ → otro link.

### En la web (Hostinger)

Botones "Comprar" → linkear al Stripe Payment Link respectivo. Eso es todo. NO hace falta JS custom — Stripe procesa el pago, redirige a tu /gracias-compra.

## Métricas

| Métrica | Target |
|---|---|
| Visit → CTA click | > 25% |
| CTA click → Stripe checkout | > 80% |
| Checkout → Purchase | > 60% |
| **Visit → Purchase** | **> 8% (warm), > 2% (cold)** |
| AOV (precio medio) | 600-700€ (mix Pack + Pack+Install) |

Si **CTA click → checkout < 60%** → posible problema con velocidad página o Stripe button friction.
Si **Checkout → Purchase < 50%** → posible problema con precio percibido o método pago.
